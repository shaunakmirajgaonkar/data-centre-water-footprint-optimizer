# 💧 AquaCompute Local

100% local Streamlit dashboard for data-centre water-footprint screening and transparent optimization scenarios.

## Run
```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
python -m streamlit run app.py
```
Open http://localhost:8501.

Synthetic or authorized records only. The score is a transparent screening heuristic, not a certified physical water-footprint model.
